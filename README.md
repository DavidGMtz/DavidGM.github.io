# Portafolio de David González Martínez

Sitio profesional creado con Quarto para presentar proyectos de análisis de datos, Business Intelligence y estadística aplicada.

## Cómo trabajar desde Visual Studio Code

1. Abre la carpeta `portafolio-david` completa en Visual Studio Code.
2. Abre `index.qmd`.
3. Pulsa el botón **Preview** para ver el sitio.
4. Modifica un archivo `.qmd`, guarda los cambios y revisa el resultado.

## Dónde editar cada parte

- `index.qmd`: portada.
- `proyectos/`: fichas individuales y listado automático de proyectos.
- `blog/`: publicaciones y listado automático del blog.
- `sobre-mi/index.qmd`: perfil profesional.
- `assets/img/`: capturas e imágenes.
- `assets/cv/`: currículum descargable.
- `styles.css`: colores, tarjetas y presentación visual.
- `_quarto.yml`: menú y configuración general.

Las carpetas `_site/` y `.quarto/` son generadas por Quarto y no deben editarse ni subirse al repositorio.
