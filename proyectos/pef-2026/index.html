Proyecto: Presupuesto de Egresos de la Federación 2026

Pipeline de datos en Python y reporte interactivo en Power BI

Proyecto de Business Intelligence para analizar la distribución, administración y avance del gasto público.
Fecha de publicación

2026

Caso de Business Intelligence

Descripción del proyecto

Proyecto de Business Intelligence diseñado para analizar la distribución, administración y avance del Presupuesto de Egresos de la Federación. La solución integra un proceso de preparación de datos desarrollado en Python con un dashboard ejecutivo construido en Power BI.

El reporte permite explorar cómo se distribuye el gasto entre entidades federativas, funciones de gobierno, ramos administrativos, unidades responsables, programas presupuestarios y fuentes de financiamiento.

También facilita la comparación entre los montos aprobados, modificados y pagados para detectar diferencias en el avance presupuestario y localizar áreas con posibles rezagos.

Alcance del análisis

Preguntas que responde

El dashboard organiza la información presupuestaria mediante cinco preguntas que permiten pasar del panorama nacional al detalle de las unidades responsables.

  • ¿Dónde se concentra el gasto? Compara la distribución territorial del presupuesto entre las entidades federativas.
  • ¿En qué se gasta? Identifica los grupos funcionales, funciones, subfunciones y objetos de gasto con mayor asignación.
  • ¿Quién administra los recursos? Muestra los ramos y las unidades responsables con mayor participación presupuestaria.
  • ¿Cómo se financia? Presenta la composición del monto aprobado por fuente de financiamiento y tipo de gasto.
  • ¿Dónde existe mayor rezago? Facilita la detección de entidades y funciones con menor avance entre el presupuesto aprobado y el monto pagado.

Preparación de datos

Proceso desarrollado con Python

Python se utilizó como herramienta de extracción, exploración, validación y transformación de los datos antes de incorporarlos a Power BI. El procesamiento se documentó en un notebook reproducible disponible en el repositorio del proyecto.

  • 1. Extracción de los datos Se automatizó la descarga del archivo CSV desde el repositorio público de datos utilizando requests, BytesIO y pandas.
  • 2. Consulta de metadatos Se descargó el diccionario presupuestario en Excel para interpretar correctamente los identificadores, descripciones y clasificaciones presentes en la base.
  • 3. Análisis exploratorio Se revisaron dimensiones, tipos de datos, valores nulos, distribuciones de los montos y estructura general del conjunto de datos.
  • 4. Validación de granularidad Se definió una combinación de campos presupuestarios para comprobar que cada registro representara una observación única dentro de la estructura del gasto.
  • 5. Tratamiento de duplicados Los registros repetidos correspondientes a la misma clave presupuestaria se consolidaron mediante la suma de los montos financieros, evitando eliminar información relevante.
  • 6. Validaciones de consistencia Se compararon montos mensuales y anuales, además de revisar valores negativos asociados con ajustes, devoluciones y movimientos presupuestarios.
  • 7. Construcción del modelo estrella La base depurada se separó en una tabla de hechos y diferentes dimensiones para facilitar las relaciones y medidas utilizadas posteriormente en Power BI.
  • 8. Exportación a Parquet Las tablas resultantes se almacenaron en archivos Parquet mediante PyArrow, reduciendo el tamaño y conservando los tipos de datos.

Modelado dimensional

Modelo de datos

La estructura original contenía numerosos identificadores y niveles jerárquicos. Para facilitar el análisis se organizó la información mediante un modelo estrella.

Tabla Contenido
fact_gasto Montos aprobados, modificados, mensuales y pagados, junto con las claves que relacionan cada registro.
dim_ramo Ramos administrativos responsables del ejercicio de los recursos.
dim_ur Unidades responsables asociadas con cada ramo.
dim_func Grupos funcionales, funciones y subfunciones del gasto.
dim_programa Modalidades y programas presupuestarios.
dim_objeto_gasto Capítulos, conceptos, partidas genéricas y partidas específicas.
dim_ff Fuentes de financiamiento.
dim_entidad Entidades federativas utilizadas para el análisis territorial.
dim_tgasto Clasificación correspondiente al tipo de gasto.

Para las jerarquías de función, programa y objeto de gasto se generaron claves compuestas que permiten vincular las dimensiones con la tabla de hechos.

Visualización

Construcción del dashboard

Las tablas preparadas en Python se incorporaron a Power BI para construir las relaciones del modelo, desarrollar las medidas analíticas y diseñar las visualizaciones.

La primera parte del reporte ofrece una lectura territorial mediante un mapa de México y comparaciones entre entidades. Las siguientes vistas permiten explorar el destino funcional del gasto, los responsables de administrarlo, las fuentes de financiamiento y el avance presupuestario.

La navegación permite pasar del indicador nacional a niveles más detallados sin perder el contexto de los filtros seleccionados. De esta manera, el dashboard no solamente muestra montos: también permite explicar dónde se encuentran, quién los administra y cuál es su nivel de ejecución.

Resultado

Del dato público a una herramienta de consulta

El proyecto transforma una base presupuestaria de alta dimensionalidad en una herramienta de consulta que permite comparar territorios, clasificaciones del gasto y responsables administrativos.

La combinación de Python, modelado dimensional y Power BI proporciona trazabilidad desde la extracción de los datos hasta la presentación de los indicadores.
